# Installation

Until a release is made, only manual installation is available.


<a id="org3574a23"></a>

## Manual

To manually build Linkette, you must have Xcode installed and be able to compile for macOS 26.4. With those prerequisites met, you should be able to run the \`install.sh\` script to install it to your current user's application directory. Otherwise, follow your own \`xcodebuild\` path.
